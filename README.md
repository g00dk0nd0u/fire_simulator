# FIRE Calculator

シンプルな **FIRE（Financial Independence, Retire Early）試算ツール** です。  
年齢・生活費・資産・積立額・年金・インフレ率をスライダーで調整すると、3つのシナリオでFIRE到達年齢を比較できます。

## できること
- 入力値をスライダーで直感的に調整できます
- **直近ベース / 標準 / 保守** の3シナリオを同時比較
- 直近ベースは、各FIRE候補月について「現在→FIRE候補月」と同じ月数だけ最新確定月から遡ったS&P 500 Total Return CAGRを使用
- 標準は、1946年以降から最新確定月までの最長期間S&P 500 Total Return CAGRを使用
- 保守は、FIRE開始から想定寿命までと同じ月数について、1946年以降のS&P 500月次トータルリターンを全ローリング走査し、必要元本が最大になる実績経路を採用
- FIRE後の資産推移をグラフ表示（Chart.js）
- 入力エラー時のバリデーション表示

## 使い方
1. このリポジトリをクローン
2. `docs/index.html` をブラウザで開く（GitHub Pages 公開用ファイル）
3. スライダーを動かして結果を確認

> ビルドやサーバー起動は不要です。

## ファイル構成
- `docs/index.html` : アプリ本体（UI / 計算ロジック / グラフ描画）兼 GitHub Pages 公開用エントリ

## 計算メモ
- **Recent-based 直近ベース**: FIRE候補までの残存月数を `H` とし、最新確定月から `H` ヶ月遡った期間のS&P 500 Total Return CAGRを、その候補月の固定年率としてFIRE前の資産形成とFIRE後の必要元本計算の両方に使用します。FIREが現在月なら期間が0のためBaseの長期CAGRを使用します。
- **Base 標準**: 1946年以降から最新確定月まで、利用可能な最長期間のS&P 500 Total Return CAGRを固定年率として使用します。
- **Conservative 保守**: 固定年率ではなく、戦後の実際の月次リターン順序を使います。各FIRE候補月について「FIRE開始→想定寿命」の残存月数と同じ長さの全履歴窓を評価し、必要元本が最大になる窓をストレスケースとします。
- 保守のFIRE前資産形成はBaseの長期CAGRを使用し、FIRE後だけ履歴ストレスを適用します。
- 月間生活費は現在価値ベースで一定とし、履歴の名目月次リターンを入力インフレ率で実質化して計算します。
- 年金入力は65歳開始時の年額を基準とし、受給開始年齢に応じた繰上げ・繰下げ補正を内部で適用します。

## データ・ライブラリ
- グラフ描画: Chart.js（CDN）
- S&P 500月次履歴: `GaMa96/lfc-sp500-data` の `nomTRP` をコミット `ac66267d99aaa0f88c41f93acabc639a9a4dd908` に固定して参照。Shillerの月次価格・配当系列を基礎に、近年はS&P 500 Total Return系列で延長されたデータです。
